# Portfolio & Evidence Inventory

## Rule

The website must stop equating "portfolio" with "success cases".

Use four evidence classes:

1. `CASE_STUDY_VERIFIED`
   Completed, publishable, evidence-backed.

2. `PROFESSIONAL_EXPERIENCE`
   Real work that demonstrates capability but may not have a public measurable outcome.

3. `CURRENT_ENGAGEMENT`
   Current client/project. No success language until delivery/result is verified.

4. `PUBLIC_LAB_RESEARCH`
   Public project, demo, research or open-source work. Clearly label it as such.

## Portfolio page strategy

The first release does not need perfect case studies.

It needs:
- 3–5 professional experience cards;
- 1 public technical/lab card if strategically useful;
- 1–2 current-work cards only if publication status is safe.

Then expand individual case pages when evidence is available.
