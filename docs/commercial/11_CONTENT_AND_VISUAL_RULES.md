# Content & Visual Rules

## Goal

Add proof and richness without returning to a visually overloaded marketing site.

## Jack
Preferred media:
1. real professional photograph;
2. real flagship video;
3. evidence diagrams;
4. project screenshots only if publishable.

Do not generate a photorealistic fake Jack portrait and present it as real.

## Portfolio cards
Each card should visually encode evidence class.

Example labels:
- Professional experience
- Consulting engagement
- Public technical project
- Current work
- Research / lab

Do not use client logo walls as the primary proof mechanism.

## Client logos
Only after relationship/publication permission is clear.
SDC-engagement client logos must not imply direct Neuracode engagement.

## Technology logos
Default to text chips.
No "Partners" label unless there is an actual partnership.

## Videos
Use real thumbnails/posters.
Do not autoplay multiple social videos.
Do not load heavy third-party iframes above the fold without need.

## Diagrams
Good candidates:
- deterministic workflow -> LLM workflow -> agent -> agentic system continuum;
- Discovery -> Pilot -> Implement -> Operate;
- process/data/systems -> AI layer -> validation -> business output.

Diagrams should explain an idea, not just decorate.

## Motion
Do not add GSAP until content and evidence are complete.

If motion is later justified:
- progressive enhancement;
- transform/opacity;
- reduced motion;
- no logo morphing;
- no motion that delays LCP/content access.

## Responsive
All new content must work at:
- 320px;
- 375px;
- 768px;
- 1024px;
- 1440px+.

No horizontal overflow.
Tap targets >= reasonable accessible size.
Technology chips wrap cleanly.
Video aspect ratio remains stable.
